Research & Thesis

Undergraduate Thesis

Federated Learning for Privacy-Preserving Teen Smartphone Addiction Prediction

FedAddict is a privacy-preserving machine learning framework designed to predict smartphone addiction among teenagers without requiring centralized access to sensitive user data.

The research investigates centralized machine learning models as baselines and compares them with federated learning using distributed age-based clients. The federated framework uses FedAvg and considers non-IID data distribution across clients.
